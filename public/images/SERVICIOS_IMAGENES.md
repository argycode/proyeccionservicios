# Imágenes de Servicios

Coloca las siguientes imágenes en la carpeta `public/images/` para que se muestren cuando se haga clic en cada card de servicio:

## Nombres de archivos requeridos:

1. **servicio-venta-alquiler.png** - Para "Venta y Alquiler de Equipos a Medida"
2. **servicio-pruebas-hidrostaticas.png** - Para "Equipos para Pruebas Hidrostáticas (PH)"
3. **servicio-vaporizacion.png** - Para "Equipos para Vaporización y Desparafinación"
4. **servicio-productos-quimicos.png** - Para "Equipos para Aplicación de Productos Químicos"
5. **servicio-limpieza-cañerias.png** - Para "Limpieza y Desincrustación de Cañerías y Caños Tubing"
6. **servicio-certificacion.png** - Para "Certificación de Equipos de Alta Presión"
7. **servicio-mantenimiento.png** - Para "Mantenimiento y Reparaciones"
8. **servicio-limpieza-flota.png** - Para "Limpieza de Flota y Equipos Pesados"
9. **servicio-desgasificacion.png** - Para "Desgasificación de Cisternas"
10. **servicio-mini-vactor.png** - Para "Mini Vactor"

## Formato recomendado:
- **Formato:** PNG o JPG
- **Tamaño:** Recomendado 1200px de ancho o más para buena calidad
- **Peso:** Optimizar las imágenes para web (menos de 500KB cada una)

## Funcionalidad:
- Al hacer clic en cualquier card de servicio, se abrirá un modal mostrando la imagen correspondiente
- El modal se puede cerrar haciendo clic en la X, fuera de la imagen, o presionando la tecla Escape
- Las cards con imágenes tienen un cursor pointer y un efecto hover mejorado
